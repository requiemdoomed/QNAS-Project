# data/

Put MedMNIST files here if you want to run on the medical datasets, e.g. `data/pneumoniamnist.npz`
(download from https://medmnist.com or https://zenodo.org/records/10519652).
The `digits` and `breast_cancer` datasets ship with scikit-learn and need nothing in this folder.
`.npz` files are ignored by git.
